# ScoreLint

ScoreLint is an offline, explainable preflight for stained-glass SVG patterns.
It audits geometry that already exists; it does not generate art, upload designs,
or claim that software can replace a maker's judgment.

> Status: v0.1.0 implementation in progress. The executable acceptance commands
> and complete examples will replace this note before release.

See [the specification](docs/SPEC.md), [research boundary](docs/RESEARCH.md), and
[implementation plan](tasks/plan.md).
