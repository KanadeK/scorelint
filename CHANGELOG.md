# Changelog

All notable changes to ScoreLint are documented here.

## [0.1.0] - 2026-08-30

### Added

- Physical SVG parsing for common closed shapes, paths, curves, arcs, and transforms.
- Measured findings for invalid contours, overlap, sharp tips, tight notches, narrow
  sections, small pieces, and missing stable IDs.
- Deterministic JSON, CSV, annotated SVG, and standalone HTML reports.
- Stable `0`, `1`, and `2` CLI exit semantics for local and CI workflows.
- Dependency-free runtime package, documented examples, cross-platform verification,
  and release assets.
